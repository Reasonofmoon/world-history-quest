# 세계사 익힘 탐험

중학교 역사① 가운데 송의 건국부터 신해혁명까지를 19차시로 익히는 학습 웹앱입니다.

- 차시마다 핵심 정리(빈칸), 용어 카드, ○× 퀴즈, 순서 세우기, 실전 문항, 서술형, 기억법, 영상 찾기
- 시험 대비: 범위 점검표(56개 요소), 전 범위 모의고사 20문항, 시험 직전 한 장
- 연표, 종합 평가 2회, 오답 노트, 기억법 실험실
- 우리 반: 학생이 진도 코드를 복사해 보내면 교사가 붙여 넣어 반 전체 진도를 표로 봅니다.

로그인 없이 링크만으로 씁니다. 학습 기록은 각자의 브라우저에만 저장됩니다.

## 파일

- `index.html` 앱 전체(외부 라이브러리 없음, 글꼴만 Google Fonts)
- `data.json` 차시·문항 데이터(객관식 114문항, 정답과 해설 포함)

## 알아 둘 점

- 문항과 정리는 수업 학습지 범위를 바탕으로 새로 쓴 것입니다. 교과서와 표현이 다르면 교과서를 따르세요.
- 영상 단계는 유튜브 검색 결과로 연결합니다.
